# Inventory System (WIP)

This is the begging of a project I hope to expand as I develop my programming skills.

To run this program, enter up to 30 items into the input box when prompted, seperate each item by a seperate line. 
This will add an item to your inventory. 
If you want to remove something, say "Remove" + a space and an item in your inventory. Must be word for word and case for case.
If you want to add something at a specific index, say "Add" + a space + item + the index (1-30).
